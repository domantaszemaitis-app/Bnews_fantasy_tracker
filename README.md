# Draft Tracker

Live stats and Basketnews **Modern** fantasy scores for your EuroLeague draft team.

## Start (Windows)
1. Install Python from https://www.python.org/downloads/ . Tick **"Add python.exe to PATH"** on the first screen.
2. On this GitHub page click the green **Code** button, then **Download ZIP**, and unzip it.
3. Double-click **start.bat**. Your browser opens the dashboard. Keep the black window open while using it.
4. The first load takes a few minutes. After that it refreshes every 30 seconds.

## Use
- **All players**: tap the star to add a player to your team (saved in your browser).
- **My team**: fantasy points per round, season averages, LIVE marker during games.
- Click the role button to switch a player between Starter / Bench / Captain (x1 / x0.5 / x2).

The app checks GitHub for a newer version every time you start it, so you never need to download again.
Season settings are at the top of `server.py` (`SEASON = "E2026"`).
